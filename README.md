# Cypher — канал обновлений

Отсюда приложение Cypher скачивает обновления. `latest.json` подписан ключом администратора; приложение проверяет подпись, размер и SHA-256 установщика перед установкой.

## Cypher 1.1.1 — Operator и Voice 2.0

В 1.1.1 исправлена потеря акустической активации при пустой расшифровке. Пустой или ошибочный текст не становится командой. После ошибки или тайм-аута Operator требует заново прочитать окно; одновременные действия по одному старому наблюдению не дублируются.

Обновление для установленных версий 1.0.9, 1.0.10 и 1.1.0. Проверить обновления можно в приложении. Для новой установки сначала установите `Cypher_1.0.9_x64-setup.exe`, затем обновитесь.

- **Operator:** в Agent Mode доступны поиск окон, чтение доступных элементов и текста, нажатие кнопок, выбор элементов и заполнение полей через Windows UI Automation. Изменения требуют подтверждения конкретного шага. После изменения агент заново читает окно. Поля паролей исключены; поля только для чтения защищены от записи. Поддержка зависит от интерфейсов доступности конкретной программы; универсальное управление любым документом не гарантируется.
- **Voice 2.0:** локальная акустическая активация по имени «Сайфер» / «Cypher» перед запуском расшифровки речи. Добавлены модели для русского и английского, мягкое шумоподавление и паузы между предложениями Piper. Используются прежние голоса Piper, а не новая модель синтеза.

Если голосовой пакет Voice 2.0 ещё не установлен, **переустановите голосовой пакет в настройках голоса**, чтобы загрузить новые зависимости и модели активации. При переходе с 1.1.0 на 1.1.1 уже установленный пакет менять не требуется. Затем включите голосовой режим и активацию по имени. Для Operator включите инструменты и откройте Agent Mode, например: «Посмотри открытые окна и заполни поле в документе».

Обновление сохраняет установленную оболочку 1.0.9: номер версии оболочки может остаться прежним, версия backend становится 1.1.1. Установщик проверяет исходные файлы, создаёт резервную копию и не изменяет пользовательские настройки.

Проверки: 36 автоматических тестов; Windows — обновление, запуск, авторизация API, DPAPI, повторная установка, реальные элементы UI Automation и 14 синтетических голосовых примеров на двух языках. Голосовая проверка на синтетических примерах не заменяет проверку с реальным микрофоном и фоновым шумом.
