# Cypher — канал обновлений

Отсюда приложение Cypher скачивает обновления. `latest.json` подписан ключом администратора Ed25519; приложение проверяет подпись, размер и SHA-256 установщика перед установкой.

## 1.0.10 — исправления безопасности серверной части

Пакет `Cypher_1.0.10_x64-update.exe` предназначен для установленной версии 1.0.9. Он обновляет Python-backend до 1.0.10; готовая оболочка `Cypher.exe` остаётся версии 1.0.9. Это пакет исправлений, а не установщик с нуля. Для более старых версий сначала установите 1.0.9.

- Строгая проверка манифеста, ограничение его размера и запрет переходов обновления на HTTP.
- Защита от одновременных установок и непредсказуемые временные каталоги для загрузок.
- Атомарная запись зашифрованных секретов через эксклюзивный временный файл.
- Ограничение размера голосовых библиотек до проверки контрольной суммы.

Установщик проверяет исходные файлы 1.0.9, закрывает Cypher и создаёт резервную копию заменяемых файлов в `%LOCALAPPDATA%\Cypher-update-backups`. Пользовательские чаты, настройки и ключи не заменяются. При ошибке записи установщик восстанавливает уже заменённые файлы. После успешной установки Cypher запускается снова.

Проверено: 15 локальных тестов; установка, запуск оболочки и backend, отказ в доступе к API без токена, Windows DPAPI и повторная установка на Windows в GitHub Actions. Полный аудит всех функций приложения не выполнялся.
